# 💼 Personal Portfolio Website

A modern and interactive **Personal Portfolio Website** built using **HTML, CSS, and JavaScript**.  
The website uses a **3D book/page-turning design** to present profile information, education, projects, services, skills, and contact details.

## 🌐 Live Portfolio

You can host this project using GitHub Pages, Netlify, or Vercel.

---

## ✨ Features

- 📖 Interactive 3D book-style portfolio
- 🔄 Animated page-turning effect
- 👤 Personal profile section
- 🎓 Education details
- 💻 Personal projects section
- 🛠️ Services section
- 🧠 Skills and technologies section
- 📱 Social media links
- 📩 Contact form
- 📄 Resume download button
- 🎨 Modern responsive UI
- ✨ Smooth CSS animations
- 📱 Responsive design for different screen sizes
- 🎯 Boxicons for icons

The portfolio contains sections for education, projects, services, skills, and contact information.

⚡ Interactive Page Turning
JavaScript controls the 3D page-turning animation.
Users can:
- Move to the next page
- Return to the previous page
- Open the contact section
- Return to the profile page
The page-turn logic is implemented using elements with the .nextprev-btn class and the .turn CSS class.
